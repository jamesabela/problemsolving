About Python Code Lab

This companion website integrates with Python Code Lab (pythoncopy.html), an in-browser Python runner powered by Pyodide.

Key Features of Python Code Lab:

  • Zero Installation: Runs python scripts directly inside your browser.
  • Step-by-Step Tracing: Visualise variables and execution line-by-line using Display Mode.
  • Self-Checking Quizzes: Some challenges have built-in tests that automatically verify if your solution works.
  • Browser-Safe: Includes support for basic libraries like random, math, turtle graphics, and more.

How it Works:

When you click "Run in Python Code Lab", the website packs the script using Base64 encoding and appends it to the Code Lab URL. This enables the IDE to open with the script pre-loaded and ready to run immediately.
